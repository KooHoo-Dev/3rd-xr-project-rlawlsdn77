# Quick Draw 컨셉 기획서

## 어떤 게임인가

Quick Draw는 권총으로 표적을 맞히는 VR 사격 게임입니다.

- 제자리에 서서 총을 잡고 표적을 쏩니다.
- 탄이 떨어지면 탄창을 손으로 직접 갈아 끼웁니다.
- 30초 라운드 3번 동안 점수를 모읍니다.

## 핵심 게임 루프

[핵심 게임 루프 · 4단계 반복]

라운드가 올라갈수록 표적이 작아지고, 앞 라운드의 등장 방식에 새 방식이 하나씩 더해집니다. 3라운드가 끝나면 결과 화면에 점수와 명중률이 나오고, MENU 버튼을 쏘면 메뉴로 돌아가 다시 시작할 수 있습니다.

## 조작 방법

| 동작 | 컨트롤러 입력                        | 설명 |
| --- |--------------------------------| --- |
| 총 잡기 | 오른손 그립 버튼                      | 테이블 위 총에 오른손을 가져다 대면 스냅 가이드라인이 먼저 보이고, 그립하면 손에 붙습니다. 놓치면 2초 뒤 테이블로 돌아옵니다. |
| 발사 | 총을 쥔 상태로 트리거                   | 누를 때마다 한 발 나가고, 꾹 눌러도 한 발입니다. 레이저 사이트로 조준합니다. |
| 탄창 빼기 | 총을 쥔 오른손의 A 버튼                 | 뺀 탄창은 바닥에 떨어집니다. |
| 탄창 끼우기 | 왼손으로 테이블 탄창을 집어 총 아래에 대고 위로 밀어 올리기 | 총 아래에 갖다 대면 탄창이 끼울 자리에 스냅되고, 위로 미끄러지듯 올리면 끼워집니다. 끝까지 올리기 전에 손을 놓으면 탄창이 떨어집니다. |
| 장전 | 왼손으로 총 위의 슬라이드를 잡아 뒤로 당겼다 놓기 | 탄창을 끼울 때마다 슬라이드를 당겼다 놓아야 장전이 끝납니다. 장전 전에는 방아쇠를 당겨도 딸깍 소리만 납니다. |

## 게임 규칙

- 한 판은 30초 라운드 3번입니다. 라운드 사이에 10초 휴식이 있습니다.
- 총은 항상 오른손, 탄창과 슬라이드는 항상 왼손으로 잡습니다. 반대 손으로는 잡히지 않습니다.
- 매 판은 빈 총으로 시작합니다. 결과 화면에서 MENU를 쏘면 총에 끼워진 탄창이 빠지고 남은 탄도 비워집니다. 테이블의 탄창을 끼우고 슬라이드를 당긴 뒤 START를 쏩니다.
- 표적을 맞히면 +10점입니다. 감점은 없습니다.
- 탄창은 10발이고, 테이블에서 몇 개든 가져올 수 있습니다.
- 탄이 남은 탄창을 빼면 남은 탄은 버려집니다.
- 버튼은 손으로 누르지 않고 총으로 쏴서 누릅니다. 메뉴에서 START 표적을 쏘면 시작하고, 결과 화면에서 MENU 표적을 쏘면 메뉴로 돌아갑니다.

## 표적 등장 방식

표적은 모두 정면 5\~15m 거리에 나오고, 라운드가 끝나면 남은 표적은 한꺼번에 쓰러집니다.

| 라운드 | 크기 (반지름) | 나오는 방식 | 맞히면 |
| --- | --- | --- | --- |
| 1라운드 | 0.5m | 정해진 7개 자리 중 빈 곳에 나타났다가 잠시 뒤 사라짐 | 바로 사라짐 |
| 2라운드 | 0.35m | 1라운드 방식 + 아래에서 위로, 또는 위에서 아래로 지나가는 표적 | 바로 사라짐 |
| 3라운드 | 0.25m | 2라운드 방식 + 여러 표적이 한 묶음으로 아무 방향으로 지나감 | 맞은 표적만 사라지고, 묶음의 나머지는 계속 움직임 |

- 세로로 지나가는 표적은 나올 때마다 방향(위로 / 아래로)이 정해집니다.
- 표적 묶음은 가장자리에서 나와 중앙을 지나 반대쪽 가장자리로 빠져나갑니다.
- 표적 묶음은 나올 때마다 방향이 정해지고, 대각선으로도 지나갑니다.

## 핵심 기능

- **탄창 직접 교체**: 버튼이 아니라 빼고, 집고, 끼우고, 슬라이드를 당기는 손 동작으로 재장전합니다.
- **스냅 가이드라인**: 총이나 탄창에 손을 가져다 대면 잡힐 자리에 반투명한 총·탄창이 먼저 보이고, 그립하면 그 자리에 붙습니다.
- **레이저 사이트**: VR이 처음인 사람도 쉽게 조준할 수 있습니다.
- **3단계 난이도**: 라운드마다 표적이 작아지고, 등장 방식이 하나씩 늘어납니다.
- **결과 화면**: 점수와 명중률(맞힌 수 ÷ 쏜 수)을 보여주고, 버튼은 메뉴로 돌아가는 MENU 하나만 있습니다.
- **남은 탄 표시**: 총 뒤쪽에 숫자로 보이고, 0발이면 슬라이드가 뒤로 멈춥니다.
- **효과음과 진동**: 쏠 때마다 소리와 컨트롤러 진동으로 손맛을 줍니다.
